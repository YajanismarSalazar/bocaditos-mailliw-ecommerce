# Bocaditos Mailliw — E-commerce de Repostería

Aplicación web de comercio electrónico desarrollada como proyecto de portafolio para Ingeniería en Sistemas.

## Características
- Catálogo estructurado con precio, categoría y disponibilidad.
- Filtrado por categorías en tiempo real.
- Carrito de compras con cálculo de subtotal, empaque (5%) y total.
- Generación de comprobante de orden.
