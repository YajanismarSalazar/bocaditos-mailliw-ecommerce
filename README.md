# \# Bocaditos Mailliw — E-commerce de Repostería

# 

# Aplicación web de comercio electrónico desarrollada como proyecto de portafolio para \*\*Ingeniería en Sistemas\*\*, orientada a la gestión y confirmación de pedidos de repostería artesanal.

# 

# \## Demo en vivo

# \- \*\*Sitio web:\*\* `https://yajanismarsalazar.github.io/bocaditos-mailliw-ecommerce/`

# 

# \## Características

# \- Catálogo estructurado con precio, categoría, descripción y disponibilidad (`stock`).

# \- Filtrado por categorías en tiempo real.

# \- Carrito de compras interactivo con control de cantidades, cálculo de \*\*subtotal\*\*, \*\*empaque (5 %)\*\* y \*\*total a pagar\*\*.

# \- Generación de comprobante de orden en pantalla y copia automática al portapapeles.

# \- Botón \*\*CONFIRMAR PEDIDO\*\* que envía la comanda estructurada directamente a \*\*WhatsApp\*\*.

# 

# \## Tecnologías utilizadas

# \- \*\*HTML5\*\* (`index.html`)

# \- \*\*CSS3\*\* (`styles.css`)

# \- \*\*JavaScript\*\* (`app.js`)

# \- \*\*GitHub Pages\*\* para despliegue estático
