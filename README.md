# Bocaditos Mailliw — E-commerce de Repostería

Aplicación web de comercio electrónico desarrollada como proyecto de portafolio para Ingeniería en Sistemas, orientada a la gestión, pago móvil y confirmación de pedidos de repostería artesanal.

## Demo en vivo
- Sitio web: https://yajanismarsalazar.github.io/bocaditos-mailliw-ecommerce/

## Características
- Filtros principales: **Tortas completas**, **Porciones** y **New York Cookies**.
- Tarjeta unificada de **Tortas completas** ordenada de menor a mayor precio por tipo (**Torta Triple Chocolate** 16 cm $30 / 24 cm $60, **Marquesa de Pirulín** 16 cm $30 / 24 cm $60, **Torta Beso de Ángel** 16 cm $35 / 24 cm $60 y **Pies Completos** 24 cm Parchita/Limón $40).
- **New York Cookies** con rellenos: Chocolate Blanco ($3.50), Nutella ($4.50), Ovomaltina ($4.50), Samba ($4.50), Brownie con Caramelo Salado ($5.50) y Brownie con Nutella ($6.00).
- **Porciones** reunidas en una sola selección.
- Modalidad de entrega **Pick up** o **Delivery** (**Barcelona $3**, **Lechería $4**, **Puerto La Cruz $5**), empaque (5 %), datos de Pago Móvil (`0172 - Bancamiga`, `04129424001`, `J208837067`), número de comprobante, carga de capture, botones **CONFIRMAR PEDIDO** y **SEGUIR COMPRANDO**, y envío a WhatsApp.

## Tecnologías utilizadas
- HTML5 (`index.html`)
- CSS3 (`styles.css`)
- JavaScript (`app.js`)
- GitHub Pages para despliegue estático
